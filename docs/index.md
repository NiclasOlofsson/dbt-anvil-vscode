# dbt Studio

A VS Code extension that gives dbt the same kind of language support that most programming languages have had for years. Now it's here, for dbt Core.

[View on GitHub](https://github.com/NiclasOlofsson/dbt-studio-vscode) · [Install from Marketplace](https://marketplace.visualstudio.com/items?itemName=nickeolofsson.dbt-studio-vscode)

![dbt Studio demo](https://raw.githubusercontent.com/NiclasOlofsson/dbt-studio/main/demo.webp)

## What you get

- Column intelligence
- Interactive lineage
- SQL debugger and profiler
- Test explorer
- Copilot tools for dbt workflows
